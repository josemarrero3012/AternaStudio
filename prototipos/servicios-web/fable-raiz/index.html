Preguntas frecuentes

¿Cuánto tarda?
Depende del alcance, pero una web a medida suele estar entre 3 y 6 semanas desde que tenemos el contenido. Te damos un calendario antes de empezar.
¿El código es mío?
Sí. Te entregamos el código y es tuyo. Está escrito para que otro estudio pueda seguir con él si algún día cambias de proveedor.
¿Incluye el mantenimiento?
El mantenimiento (hosting, copias, actualizaciones, soporte) es un servicio aparte y opcional. Puedes contratarlo o llevar la web por tu cuenta.
